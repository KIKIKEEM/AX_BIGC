정책 제안(공식 문서 아님): 개인 Free, Pro, Max 계정으로 회사 자료를 입력하지 않도록 권고. 학습 설정이 개인 판단에 달려 있고 상업 계정과 조건이 다르기 때문. 리더용 민감도 3단계 예시: 공개(사용 가능), 내부(승인된 상업 계정에서만), 기밀과 개인정보와 계약과 미공개 재무(사용 금지 또는 회사가 별도 승인). 기준은 회사가 정해야 함.

- 비개발자 전원: 레벨 0에서 숙제인 '스킬 만들기'를 시작한다. 코드가 필요 없고 업로드까지 가능하다.
- 3주 목표선은 레벨 2(데스크톱 Code 탭). "Claude Code 데스크톱을 깔아야 하나?"에 대한 답은 "데스크톱 앱을 설치하면 Code 탭을 쓸 수 있고 터미널은 필요 없다. 단 Pro 이상 유료 플랜이 필요하다"이다.
- 레벨 3은 개발자 대상이다.
- 선행 조건: Free 계정으로는 Code 탭과 Claude Code를 쓸 수 없으므로 Pro 이상 또는 회사 Team 계정을 먼저 준비해야 한다.
