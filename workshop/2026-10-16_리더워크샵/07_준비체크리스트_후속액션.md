# 07. 준비 체크리스트와 후속 액션

## 준비 체크리스트 (10/15 목 밤 ~ 10/16 금 10:20)

### 오늘 밤 (10/15)
- [ ] 구글 시트에 모인 팀별 AX 과제 템플릿을 읽고, 리더별로 1장씩 출력. 각 장에서 '핸들 노동 후보' 문장 1개에 형광펜.
- [ ] 제출 현황 표시(완성/절반/미제출). 미제출 리더가 입양할 만한 시드 카드를 메모.
- [ ] 클러스터 구역 지도 확정(B2B·CRM / 아티스트·스케줄 데이터 / 마케팅·콘텐츠 / IR·경영정보 / 개발 지식 / 기타 운영). 겹치는 후보 표시.
- [ ] 시드 카드 9장 출력(과제 풀 카드에서 ②핸들 노동 ③목적지만 남김). 엔터 OS는 파킹 랏 카드로 따로.
- [ ] 덱 최종본: 균님 슬라이드 3~4장은 04번 뒤에 끼우거나 균님 노트북으로 전환. 오프닝 사례 슬라이드의 출처를 한 번 더 확인. S10 '예시이며 실측치 아님', S11 '예시' 표기 확인. 출처가 불분명한 수치는 모두 삭제.
- [ ] 페어 배치표(개발/비개발 섞기, 같은 파트 피하기, 대표 + 균님 + 비개발 리더 1명 트리오).

### 사전 연락 (오늘 밤, 대표님은 메시지가 아니라 통화로)
- [ ] 대표(통화): ① 곧 나갈 공지의 확정 문구와 발송일 ② 워크샵 화면·카드에 공지 문구를 인용해도 되는지 ③ ‘인력을 줄이지 않는다’를 약속할 수 있는지 → 오프닝 첫 문장 확정(약속 못 하면 ‘오늘은 사람이 아니라 업무 단계를 이야기합니다. 인력·채용 질문은 걱정 카드로 받아 끝날 때 언제까지 답할지 말씀드리겠습니다’) ④ 걱정 응답 틀 ‘지금 말할 수 있는 것 / 아직 정하지 않은 것 / ○월 ○일까지 어떤 채널로’와 예상 테마 5개(역할·일자리, 못 따라갈까, 검증 일이 더 늘까, 평가 반영, 데이터·보안)에 한 문장씩 ⑤ ‘대표 지정 1장’ 규칙(이유 공개, 리더가 고른 카드는 불변) ⑥ 오늘 확정한 Top은 오후 Q4 리뷰에서 바꾸지 않기
- [ ] 대표: 오프닝 60초 문장 2개, 투표하지 않고 금별 최대 3개, 자기 카드 1장, 트리오에서 먼저 심문받기, 리더 투표 중 벽 앞에 서지 않기, 걱정 테마 응답 범위('지금 말할 수 있는 것'과 '공지 전 서면 답변'), 공지 문구는 워크샵에서 논쟁하지 않기.
- [ ] 균님(이름·직함 표기 회신 요청): 6분 하드스톱, 4질문 구조, 확인된 수치만, '약 90%'의 분모 확정, 결과물 샘플 1건 선정(틀리거나 빈 필드가 있는 건 권장), 예시 출제 카드 공동 작성, '작업 단계와 시간'의 언어로 말하기 합의. 리허설 10분 시간 잡기.
- [ ] 세나님(이름·직함 표기 회신 요청): 보도자료 판단 기준 초안 수신 여부, 루브릭 예시로 써도 되는지 동의.
- [ ] 운영 담당: 10/29 참여 개발자 수(팀 수 상한), 10/29 요일(달력상 목요일, 노션 메모는 ‘수’) 확인, 리더 실제 참석 인원, 보조 인력 1명(사진) 가능 여부, 라운지 사진과 테이블 수, 벽 3면 마스킹테이프 부착 가능 여부, 09:00부터 사용 가능 여부, 12:00 이후 공간 일정(Q4 리뷰 장소).
- [ ] 관계 담당(B2B·영업) 파트장: 내일 09:30 전 5분 통화. ‘관계 내용은 쓰지 않고 팔로업 손노동만 다룹니다’를 미리 전한다.
