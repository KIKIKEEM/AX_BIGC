### 2.2 공통 판정 규칙

| 규칙 | 내용 |
|---|---|
| n | 리더 응답 수. **대표 응답은 리더 집계에서 뺀다**(② 별도 보고). |

### 2.5 시작 경로 판정 규칙 (D1: "무엇을 깔아야 하나")

전원이 Claude Code를 깔 필요는 없다. 스킬은 claude.ai 웹의 Customize > Skills에서 코딩 없이 만들 수 있고 Free를 포함한 전 플랜에서 쓸 수 있다(코드 실행 활성화 필요, TF §3-6·7·8). Claude Code는 데스크톱 앱 Code 탭에서 터미널 없이 쓸 수 있지만 Pro 이상 또는 회사 Team 플랜이 필요하고(TF §1-5·6·11), 터미널 CLI는 개발자용이다(TF §6). 그래서 **B와 C의 경계는 터미널이 아니라 계정(유료 여부)**이다. 숙제(스킬 1개)는 세 경로 모두 '스킬'로 낸다 [제안]. 레벨 표기는 14_도구_사실확인.md §6(레벨 0~3)을 따른다.

| 경로 | 시작 도구 | 조건 | 첫 2주 목표 |
|---|---|---|---|
| **A** 설치 최소 (레벨 0) | claude.ai 웹(무료 계정 가능) + Aside(설치 가능하면) | Q11 '승인 필요·모름'(정책 확인 전) **또는** Q20 ① | 웹 Customize > Skills에서 스킬(맥락·완료 조건·루프를 적은 지시서) 1개를 만들어 3회 돌려 보고 고치기 → 권한·계정 해결 시 B/C |
| **B** 데스크톱 앱 (레벨 1) | Claude 데스크톱 앱(Chat) + Aside | Q11 직접 설치 가능(또는 승인 완료) **그리고** Q10 Claude '안 씀·무료·모름'(유료 계정 없음) | 앱 설치·로그인까지 마쳐 두기(유료 계정이 생기면 바로 Code 탭) + 웹에서 스킬 1개, 3회 써 보고 고침 |
| **C** Claude Code (레벨 2, 개발자는 3) | 데스크톱 앱 Code 탭(터미널 불필요) + Aside. Q12 4~5나 개발 리드는 터미널 CLI도 | Q11 직접 설치 가능 **그리고** Q10 Claude '내 돈으로 유료' 또는 '회사가 결제' | 반복 업무 스킬 1개 완료(Code 탭에서 실행) → 해커톤 도구 버디 후보 |

- 조정: Q20 선호를 환경이 허락하는 범위에서 한 단계 위·아래로 반영한다. Q20 ④는 환경 규칙 그대로. Q20 ③인데 유료 계정이 없으면 B로 두고 D3 플랜 안건 인원에 센다. Q13 스킬 '이미 해 봄'이면 현재 도구 유지.
- 3주 목표선은 C의 레벨 2(데스크톱 Code 탭)로 두되, 유료 계정 준비(D3)가 먼저다 [제안, TF §6 권고].
- 개인 계정(Free·Pro·Max)은 학습 데이터 사용 여부가 개인 설정에 달려 있으므로(TF §5) 어느 경로든 회사 민감 자료는 넣지 않게 안내한다 [제안, 회사 기준은 D4].
- 개인 배정은 ③ 신청자(S2 '시작 지점 추천')에게만 한다. 나머지는 시작 경로 가이드(backup_plan M2)의 자가 진단 트리로 스스로 고른다. 설문은 응답 행마다 규칙을 적용해 **경로별 인원**을 세고, 체크리스트 제작 순서와 분량을 정하는 데 쓴다.

### 3.3 회상(Q3) 채점 기준

| 키 | 2점(정확) | 1점(부분) | 0점 |
|---|---|---|---|
| **맥락 정보** | 맥락·배경을 준다 + 내용 1개 이상(전문가 노하우·암묵지, 고객 니즈, 나의 선호) 또는 이유 | '맥락', '배경 설명', '자료·정보를 많이 준다' 같은 키워드만 | 없음, 또는 '프롬프트를 잘 쓴다' 같은 일반론 |
| **완료 조건** | 무엇이 되면 끝인지 미리 정한다 + 이유(AI는 잘됐는지 스스로 판단하지 못함) 또는 예(체크리스트, 합격 기준) | '기준', '목표를 명확히', '평가 기준' | 없음, 또는 '결과를 검토한다'만(→ 오개념 M2) |
| **루프** | 완료 조건을 채울 때까지 반복 + (평가는 별도 세션 **또는** 작게 하나씩 실험) | '반복', '피드백 주고받기', '여러 번 돌린다' | 없음 |

- 키당 0~2, 합계 0~6. 1점과 2점 경계가 애매하면 1점. 분모는 Q2 '모두 + 1부만'.
- 오개념: **M1** '프롬프트 문장만 잘 쓰면 된다' / **M2** '결과 검토 = 완료 조건' / **M3** '같은 대화에서 AI가 스스로 평가하게 한다'.

- 리포트: 키별 회상률(1점 이상), 정확 회상률(2점), 평균 합계, '모름' 수, 기타 회상 Top 3.
