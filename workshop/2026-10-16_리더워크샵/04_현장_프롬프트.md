## 1. AX 출제 카드 Grill-me (10/22 숙제, 카드 v2 → 최종본)
```
너는 BIGC(엔터테크 스타트업) 사내 해커톤의 출제 검토관이다. 아래는 내가 쓴 AX 출제 카드다.
이 카드의 모든 측면에 대해 집요하게 질문해 줘. 우리가 같은 이해에 이를 때까지 결정들 사이의 의존 관계를 하나씩 풀어 줘.

규칙:
- 질문은 한 번에 하나씩만. 질문마다 너의 추천 답을 함께 줘.
- 해결책(어떤 툴로 어떻게 만들지)은 제안하지 말고, 판단 기준을 파고들어.
- 다음 순서로 따져 줘.
  1) 핸들 노동과 목적지가 섞여 있지 않은가
  2) 결과를 누가 어떤 결정에 쓰는가
  3) 완료 조건이 10/29 하루 안에 판정 가능한가(예/아니오 2개, 숫자 1개, '좋다'의 기준)
  4) 완료 조건을 통과하지만 실제로는 쓸모없는 결과물(가짜 합격)은 무엇인가
  5) AI가 틀렸을 때 누가 어디서 처음 알아채는가
  6) 데이터는 어디에, 누구 권한으로, 몇 건 있으며 외부로 나가도 되는가
  7) 3인조(개발 1, 비개발 2)가 하루에 시연할 수 있는 가장 작은 버전은 무엇인가
- 내가 '?'라고 쓴 칸은 반드시 다뤄 줘.
- 내가 "정리"라고 하면 수정된 카드 전체를 같은 칸 구조로 다시 써 줘. 확인되지 않은 수치는 [추정]으로 표시해 줘.
- 마지막에 ⑥ 의도 메모 3줄(지금 이렇게 하는 이유, 내가 판단할 때 보는 것)을 뽑아 줘. 관계 내용은 [관계 정보]로만 표시해.
```

## 2. 핸들 노동 / 목적지 분해 (빈 템플릿을 들고 온 리더용, 사전 또는 오후)
```
나는 BIGC [파트명] 리더다. 우리 팀이 한 주 동안 하는 일을 아래에 적었다.
이것을 '핸들 노동'(손으로 반복하는 수집·입력·옮기기·정리 단계)과 '목적지'(그 일로 누가 어떤 결정이나 행동을 하게 되는가)로 나눠 줘.

출력 형식(표):
| 업무 | 핸들 노동 단계 | 목적지(결정/행동) | 빈도·소요시간 [추정] | 입력 데이터 위치 | AI 활용 단계(1~6) 제안 |

규칙:
- 사람을 평가하거나 인원 수를 줄이는 관점으로 쓰지 마. 업무 단계 단위로만 써.
- 내가 주지 않은 수치는 만들지 말고 '[확인 필요]'로 남겨.
- 마지막에 10/29 하루 해커톤에 적합한 후보 2개를 골라 이유를 한 줄씩 붙이고, 각 후보에 대해 나에게 확인해야 할 질문 1개씩을 던져 줘.

[팀 업무 목록 붙여 넣기]
```

## 3. 완료 조건 초안 생성 (오리 테스트 3층)
```
아래 AX 과제의 '완료 조건' 초안을 만들어 줘. 10/29 오후 5시에 오너가 이 표만 보고 합격/불합격을 판정할 수 있어야 한다.

과제명: [ ]
목적지·가설: [ ]
하루 MVP: [ ]
입력 데이터 유형: [ ]

출력:
1층 예/아니오 체크 2~3개(반드시 있어야 하는 것)
2층 숫자 합격선 1~2개(측정 방법과 표본 수 포함. 기준값은 내가 정하도록 빈칸 '__'으로 남겨)
3층 '좋다'의 기준 루브릭 2~3개(각 1~3점, 점수별 설명 한 줄)
가짜 합격 사례 2개와 그것을 막는 추가 체크
판정 방법: 누가, 무엇과 대조해서, 몇 분 안에

규칙: 확인되지 않은 업계 통계나 수치는 쓰지 마. 내가 판단할 때 볼 것 같은 기준을 추측했다면 [추측]으로 표시하고, 마지막에 나에게 확인할 질문 3개를 한 번에 하나씩 순서대로 제시해 줘.
```
