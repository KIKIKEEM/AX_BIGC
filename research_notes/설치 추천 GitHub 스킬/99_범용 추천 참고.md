# 범용 GitHub 스킬 참고 목록 (이 문제와 무관한 일반 추천, 미검증)

> 다른 조사 에이전트가 범위를 오해해 만든 일반 추천 목록입니다. 별 수와 설명은 검색 결과 기준이며 저장소 내용을 직접 검증하지 않았습니다.

아래는 이미 설치된 스킬(anthropic-skills 세트, deep-research, ebp, kikitv, adobe, figma, zapier, wix, finance, base44 등)을 뺀 GitHub 추천 목록입니다. 별 수와 내용은 2026-10-14에 GitHub 검색과 README로 확인했습니다. 설치 전 테스트는 하지 않았습니다.

**업무 활용 (마케팅·기획)**
1. **coreyhaines31/marketingskills** (★54.6k): 마케팅 스킬 50개입니다. analytics, attribution, ab-testing, cro, content-strategy, social, customer-research, marketing-plan 등이 들어 있습니다. 설치는 `npx skills add coreyhaines31/marketingskills`(필요한 것만 받으려면 `--skill analytics ab-testing`)이고, 플러그인으로는 `/plugin marketplace add coreyhaines31/marketingskills` 뒤에 `/plugin install marketing-skills`입니다.
2. **deanpeters/Product-Manager-Skills** (★7.4k): PM 스킬 77개입니다. discovery-interview-prep(Mom Test 방식 고객 인터뷰), opportunity-solution-tree, discovery-process 등이 있어 디자인씽킹 수업에 쓸 만합니다. 설치는 `/plugin marketplace add deanpeters/Product-Manager-Skills`입니다.
3. **anthropics/skills 공식 저장소 중 아직 없는 것**: frontend-design, webapp-testing, discernment-nudge(답변 뒤에 검증용 질문을 2~3개 덧붙임), academy-guide입니다. `/plugin marketplace add anthropics/skills`로 추가하면 됩니다.

**연구 (박사과정)**
4. **WenyuChiou/ai-research-skills** (★383, MIT 라이선스): 스킬 17개로 문헌 분류표, 연구 갭 찾기, 연구설계, 논문 리뷰, Zotero 정리를 다룹니다. 설치는 `claude plugin marketplace add WenyuChiou/ai-research-skills` 뒤에 `claude plugin install research-workspace@ai-research-skills`입니다. 대학원생 1인이 만든 것이라 README에 대규모 검증은 안 됐다고 적혀 있습니다.
5. **O0000-code/paper-search-pro** (★199): OpenAlex, Semantic Scholar, PubMed, arXiv 등 5곳에서 학술 문헌을 찾아줍니다.
6. **teng-lin/notebooklm-py** (★19.7k): NotebookLM을 다루는 비공식 API이자 스킬입니다.
